# 2. GRUB Boot

Gorgon currently uses **GRUB** as its bootloader.

GRUB is responsible for:

* Loading the kernel
* Providing the Multiboot2 boot environment
* Transferring execution to Gorgon's entry point

The kernel verifies that it was started through Multiboot2 using the Multiboot2 magic value:

```asm
cmp eax, 0x36d76289
```

If the check fails, Gorgon enters its boot error routine.

---

# 3. x86 CPU Startup

The initial boot code executes in 32-bit protected mode before transitioning into x86-64 long mode.

The startup sequence currently performs:

```text
GRUB
 ↓
Multiboot2 verification
 ↓
CPUID verification
 ↓
Long-mode verification
 ↓
Initial page tables
 ↓
Enable PAE
 ↓
Enable long mode
 ↓
Load GDT
 ↓
Far jump into 64-bit code
 ↓
Load IDT
 ↓
kernel_main()
```

### CPU capability checks

Gorgon checks whether the processor supports:

* CPUID
* x86-64 long mode

Long-mode support is detected through the extended CPUID feature information:

```asm
mov eax, 0x80000001
cpuid

test edx, 1 << 29
```

Bit 29 of `EDX` indicates long-mode support.

# 5. GDT

Gorgon now has a dedicated **Global Descriptor Table** implementation.

Location:

```text
src/x86_64/cpu/gdt.asm
```

The GDT contains:

```text
Entry 0 → Null descriptor
Entry 1 → 64-bit code segment
Entry 2 → Data segment
```

The code segment selector is:

```text
0x08
```

The data segment selector is:

```text
0x10
```

The GDT is loaded while the processor is still in 32-bit protected mode:

```asm
lgdt [gdt_pointer]
```

Gorgon then performs a far jump:

```asm
jmp 0x08:long_mode_start
```

This establishes the 64-bit code segment and enters the 64-bit execution path.

### Important implementation detail

The GDT loader must use:

```asm
bits 32
```

because it is called before the transition to long mode.

The GDT pointer therefore uses the 32-bit protected-mode format:

```asm
dw limit
dd base
```

This was verified during development after an incorrect 64-bit GDT loader caused the boot process to fail.

# 6. IDT

Gorgon now has a dedicated **Interrupt Descriptor Table**.

Location:

```text
src/x86_64/cpu/idt.asm
```

The IDT reserves space for all 256 x86 interrupt vectors:

```text
256 × 16-byte entries
```

The IDT is loaded after entering 64-bit mode:

```asm
call idt_load
```

and:

```asm
lidt [idt_pointer]
```

The first interrupt vector is being prepared for:

```text
Vector 0 → Divide Error (#DE)
```

The corresponding handler is:

```asm
divide_by_zero_handler:
    cli
    hlt
```

The handler is currently intentionally minimal. It disables interrupts and halts the CPU.


The exception-handling system will be expanded during M2.

# 9. Serial Initialization

Gorgon initializes COM1 using the UART registers.

The current configuration establishes:

```text

Data bits    = 8
```

The line-control register is temporarily configured with DLAB enabled so the baud divisor can be written.

The relevant sequence is:

```asm

outb(COM1 + 1, 0x00)
outb(COM1 + 3, 0x03)
```
